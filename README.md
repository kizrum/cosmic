# Cosmic

Интерактивная карта Солнечной системы: Three.js + TypeScript + Vite.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # статическая сборка в dist/
```

## Управление

- Клик по телу, его метке или пункту списка — пролёт камеры к объекту.
- Клик по поверхности — сканирование произвольной точки; маркеры ◇ — изученные районы.
- Колесо — приближение, перетаскивание — вращение камеры.
- `Esc` — уровень назад, `Пробел` — пауза, `L` — подсветка ночной стороны.
- Дату можно задать в поле вверху (UTC), кнопка «Сейчас» возвращает к текущему моменту.

## Точность

- Планеты: элементы орбит JPL «Approximate Positions of the Planets» с вековыми скоростями
  (1800–2050 гг.; ошибка направления — сотые доли градуса).
- Спутники и карликовые планеты: элементы JPL Horizons на 19.10.2026
  (`src/data/ephemeris.ts`), для спутников — средние скорости по двум эпохам.
- Луна: теория Миуса с главными периодическими членами (~0,01°).
- Оси и вращение: IAU WGCCRE (полюса с прецессией, нулевые меридианы); синхронные
  спутники всегда обращены к планете нулевым меридианом.
- Размеры тел и расстояния сжаты степенными законами, иначе планеты были бы невидимы.
