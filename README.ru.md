# Cosmic — интерактивная карта Солнечной системы

[English](README.md) · **Русский**

**Cosmic** — научно-популярный проект. Его цель — сделать знания о Солнечной
системе наглядными, точными и доступными каждому, у кого есть браузер.

Учебники и энциклопедии рассказывают о планетах словами и цифрами. Cosmic позволяет
пролететь к ним самому. Можно увидеть, где планеты находятся прямо сейчас, рассмотреть
вулканы Ио и метановые моря Титана, найти место посадки «Аполлона-11» и узнать, который час
сейчас в кратере Гейл, где работает марсоход Curiosity.

## Зачем этот проект

- **Пробудить интерес.** Каждое тело — это не только набор чисел, но и истории открытий
  и миссий: от «Луны-9» и «Венеры-13» до Cassini, New Horizons и Perseverance. Почти на
  каждом теле есть районы, которые можно изучить, и у каждого района есть своя история.
- **Показывать настоящее небо.** Планеты, спутники и карликовые планеты стоят там, где они
  находятся на выбранную дату. День и ночь на Земле, фаза Луны и сезоны совпадают с
  реальными. Можно выбрать любую дату, например день рождения или исторический момент,
  и посмотреть, как выглядела Солнечная система тогда.
- **Опираться на науку.** Положения рассчитываются по данным NASA/JPL, ориентация осей —
  по стандартам Международного астрономического союза, карты поверхностей составлены по
  снимкам космических аппаратов. Расчёты сверены с эталонной системой JPL Horizons.
- **Честно говорить об ограничениях.** Где модель упрощает реальность, она об этом
  предупреждает: в наглядном режиме размеры и расстояния сжаты, а неотснятые области
  поверхностей показаны условно и отмечены в описании.

## Для кого

- Школьники и студенты, которые изучают астрономию и физику.
- Учителя, которым нужна наглядная модель для урока.
- Любители астрономии и все, кому интересен космос.

## Что можно делать

- Выбрать Солнце, любую из 8 планет, 20 крупных спутников, 5 карликовых планет, пояс
  астероидов или пояс Койпера и пролететь к ним.
- Изучать отмеченные районы: горы, кратеры, вулканы, места посадок, океаны, штормы.
  Районы обведены на поверхности и раскрашены по категориям.
- Нажать на любую точку поверхности: появятся координаты, время суток, высота Солнца и
  ближайший известный район.
- Смотреть строение тел: слои недр, состав атмосферы, ключевые цифры в сравнении с Землёй.
- Переключаться между наглядным и реальным масштабом.
- Ускорять время, ставить его на паузу и выбирать любую дату.
- Следить за расстоянием до Земли и временем, за которое до объекта доходит сигнал.
- Пользоваться интерфейсом на русском или английском языке.

## Научная основа

| Что | Источник |
|---|---|
| Орбиты планет | JPL, «Approximate Positions of the Planets» (элементы с вековыми скоростями, 1800–2050 гг.) |
| Орбиты спутников и карликовых планет | JPL Horizons, элементы на 19.10.2026 |
| Положение Луны | Ж. Миус, «Астрономические алгоритмы» |
| Оси и вращение | IAU WGCCRE: полюса с прецессией, нулевые меридианы |
| Карты поверхностей | NASA, JPL, USGS и снимки миссий Voyager, Galileo, Cassini, MESSENGER, Dawn, New Horizons |

Проверка по эталону JPL Horizons (`npm run check:astro`, 204 эталонных положения): в
1800–2050 годах планеты точнее 0,2° (обычно сотые доли градуса), Луна — точнее 0,03°.
Спутники, Церера и Плутон считаются по элементам на эпоху 2026 года и проверены для
2021–2031 годов: большинство точнее 1°, резонансные Мимас, Тефия и Миранда уходят до 4–5°.
За пределами этих лет приложение показывает плашку о том, что положения приблизительны.

**Масштаб.** Есть два режима. В наглядном (по умолчанию) размеры тел и расстояния сжаты
степенными законами, иначе планеты были бы невидимыми точками; порядок орбит и вложенность
систем спутников при этом сохраняются (проверка: `npm run check:layout`). Кнопка
«Реальный масштаб» (клавиша `M`) плавно переводит сцену к истинным размерам и расстояниям:
1 единица сцены = радиус Земли, 1 а.е. = 23 481 единица.

**Упрощения.** Поверхности Эриды, Макемаке и Хаумеа вблизи никогда не снимались,
поэтому их окраска условная. Части поверхностей спутников Урана, Тритона, Плутона и
Харона, которые не попали в объективы Voyager 2 и New Horizons, заполнены нейтральным тоном.

## Запуск

Нужен [Node.js](https://nodejs.org/) версии 20.19+ или 22.12+ (этого требует Vite).

```bash
npm install
npm run dev            # http://localhost:5173
npm run build          # проверка типов и статическая сборка в dist/
npm run preview        # просмотр сборки на http://localhost:4173
npm run check:layout   # проверка орбит и систем спутников
npm run check:astro    # сверка положений с эталоном JPL Horizons
npm run fetch:horizons # заново скачать эталон (нужна сеть)
```

В VS Code: `Ctrl+Shift+B` запускает dev-сервер, `F5` — сервер и Chrome с отладкой.
Остальные задачи — через «Tasks: Run Task».

## Управление

- Кнопка «Объекты» — список тел; клик по телу, его метке или пункту списка — пролёт камеры к объекту.
- Клик по поверхности — сканирование произвольной точки; клик внутри обведённого района открывает его.
- Колесо — приближение, перетаскивание — вращение камеры.
- `Esc` — уровень назад, `Пробел` — пауза, `,` и `.` — медленнее и быстрее.
- Переключатель «Масштаб» слева внизу (или клавиша `M`) — наглядный или реальный масштаб.
- Дату можно выбрать по клику на дату вверху (UTC); «Сейчас» возвращает к текущему моменту.
- Шестерёнка открывает настройки: орбиты и оси (`O`), подсветка ночной стороны (`L`), звуки
  интерфейса (`S`), язык (русский / английский), список горячих клавиш и источники.
- `I` — свернуть или развернуть панель информации.
